GOOGLE DRIVE VIDEO
------------------
For each video:
- Upload the video to Google Drive.
- Set General access to "Anyone with the link" (Viewer).
- Open the file and copy the URL.
- Example:
  https://drive.google.com/file/d/1AbCdEfGhIjKlMnOP/view
- The File ID is the part between /d/ and /view:
  1AbCdEfGhIjKlMnOP

Then edit index.html and replace:
  PASTE_DRIVE_FILE_ID_HERE

with your real File ID.

The site uses:
  https://drive.google.com/file/d/FILE_ID/preview

so the video appears inside the portfolio page rather than sending the visitor away.

CUSTOMIZE

- Add more video cards by duplicating the video blocks.
